## 🌐 Deploying to GitHub Pages (Free)

1. Create a new GitHub repository named `portfolio` (or `<your-username>.github.io`).
2. Push this folder to GitHub:
   ```bash
   cd "C:\Users\nithi\.gemini\antigravity\scratch\portfolio"
   git init
   git add .
   git commit -m "Initial commit of portfolio"
   git branch -M main
   git remote add origin https://github.com/nithissoosai20-spec/portfolio.git
   git push -u origin main
   ```
3. In GitHub Settings > **Pages**, set branch to `main` and folder to `/ (root)`. Your portfolio will be live at `https://nithissoosai20-spec.github.io/portfolio`!
